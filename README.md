# Карточка товара «Ананасовый улун»

Небольшая адаптивная страница с верхней частью карточки товара для интернет-магазина «Чайный Бум».

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, адаптивные медиазапросы)
- Vanilla JavaScript

## Запуск

Откройте `index.html` в браузере. Для локального HTTP-сервера, если он нужен редактору или браузеру, запустите в папке проекта:

```powershell
npx --yes http-server .
```

Зависимости проекта не требуются. Шрифты загружаются из Google Fonts; при недоступности сервиса используются системные шрифты.

## Возможности

- Оригинальная фотография товара и краткое описание с сайта Teaboom.ru.
- Галерея с миниатюрами; дополнительные фотографии подключаются в списке в `script.js`.
- Просмотр увеличенной фотографии товара с клавиатурным и мышиным закрытием.
- Четыре фасовки с переключением артикула и актуальной/старой цены.
- Адаптивная раскладка для мобильного, планшетного и широкого экранов.
- Управление вариантами фасовки с клавиатуры и видимые состояния фокуса.

Цены и артикулы для вариантов фасовки заданы в соответствии с условиями тестового задания.
